📘 Manual de Organização dos Apps EGI

Objetivo: manter todos os apps organizados, com nomes fixos e links estáveis, evitando que uma nova versão quebre a Central ou o Painel Início do Dia.

1. Regra principal

O melhor padrão é não fazer cada app “procurar” arquivos diferentes toda vez. Em vez disso, cada ferramenta deve ter um nome fixo oficial.

Exemplo: podem existir versões como Radar_Manada_V2.3.html, mas a versão aprovada também deve ser salva como Radar_Manada.html.

2. Estrutura recomendada no notebook

C:\MeusProj26\EGI\
│
├─ Painel_Inicio_Dia_EGI.html
├─ BTC.html
├─ Radar_Manada.html
├─ Radar_Volatilidade.html
├─ Radar_Confluencia.html
├─ Contexto_SMC.html
├─ SetupDT.html
└─ Radar_KDJ.html

Assim, o botão de um app pode abrir diretamente outro arquivo usando um endereço relativo.

3. Estrutura recomendada no celular / Render / GitHub

/public/
   index.html
   inicio-dia.html
   btc.html
   manada.html
   volatilidade.html
   confluencia.html
   smc.html
   setupdt.html
   kdj.html

O ideal é usar links relativos, por exemplo: ./manada.html, ./setupdt.html e ./kdj.html.

4. Por que isso é melhor no Android

Quando um HTML é aberto pelo Android usando um endereço do tipo content://downloads..., o navegador pode limitar o acesso direto a outros arquivos locais. Por isso, para uso confiável no celular, é melhor publicar os apps juntos no mesmo ambiente, como Render ou GitHub Pages.

5. Cadastro central com apps.json

Para evitar que cada app guarde seus próprios links, podemos criar um único arquivo de cadastro:

{
  "btc": "btc.html",
  "manada": "manada.html",
  "volatilidade": "volatilidade.html",
  "confluencia": "confluencia.html",
  "smc": "smc.html",
  "setupdt": "setupdt.html",
  "kdj": "kdj.html"
}

A Central EGI, o Painel Início do Dia e outros apps passam a consultar o mesmo cadastro.

6. Regra para novas versões

Durante os testes, mantenha o número da versão no nome do arquivo.

Radar_Manada_V2.4.html
Radar_Manada_V2.5.html

Quando uma versão for aprovada, copie também como:

Radar_Manada.html

Dessa forma, os links da Central não precisam ser alterados.

7. Arquitetura recomendada

Central EGI
   ↓
apps.json
   ↓
BTC
Manada
Volatilidade
Confluência
SMC
SetupDT
KDJ

Benefícios: menos erros, menos manutenção, links estáveis, atualização mais simples e melhor funcionamento no notebook e no celular.

8. Regra prática EGI

Versão muda; nome oficial não muda.

Esse é o princípio que mantém toda a estrutura funcionando mesmo quando os apps evoluem.
